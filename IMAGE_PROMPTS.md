# Image prompts for EEVSEC Services

The current explainer graphics are built in HTML/CSS so the site remains fast and editable. These prompts are optional image assets for future iterations. Keep generated images free of readable UI text, logos, watermarks, and fake customer metrics; the site should layer its own real copy and data on top.

## 1. Hero dashboard visual

```text
Use case: ui-mockup
Asset type: wide website hero image, 16:9
Primary request: a premium dark cybersecurity operations dashboard displayed on a slim laptop, showing abstract vulnerability trends, asset coverage, risk prioritization, and remediation progress; interface is illustrative and not tied to a real vendor product
Scene/backdrop: near-black studio background with subtle emerald telemetry lines and a soft teal glow
Style/medium: high-fidelity product UI mockup, editorial technology campaign, crisp glass-and-metal laptop
Composition/framing: laptop positioned on the right with generous negative space on the left for headline copy
Lighting/mood: controlled studio lighting, calm, precise, credible, quietly futuristic
Color palette: near-black, charcoal, emerald green, muted teal, small warm warning accents
Constraints: no readable words, no logos, no brand marks, no people, no watermark, no fake statistics
Avoid: generic hacker imagery, hooded figures, green code rain, neon overload, stock-photo look
```

## 2. Data-to-decision illustration

```text
Use case: infographic-diagram
Asset type: transparent-background or dark-background section illustration
Primary request: three connected stages transforming scattered vulnerability signals into a clean prioritized action board: raw finding dots, an organized dashboard layer, and a focused checklist of next actions
Style/medium: minimal 3D-isometric editorial illustration with thin technical lines and soft depth
Composition/framing: left-to-right flow with three distinct zones and clear spacing for a website section
Lighting/mood: precise, optimistic, intelligent, not aggressive
Color palette: black, graphite, emerald, pale mint, muted cyan, restrained amber for warnings
Constraints: no readable text, no logos, no watermark, no people, no cybercrime imagery
Avoid: complex tiny details, clutter, red-dominant palette, fantasy holograms
```

```text
Use case: ui-mockup

```
